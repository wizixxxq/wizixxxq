Инструкция

Пошаговая инструкция для новичков. Делай всё по порядку — так быстрее и без ошибок.

  1. Создай бота в Telegram Открой @BotFather, отправь команду /newbot, придумай имя и username. В ответ придёт токен — сохрани его, он понадобится позже.
  2. Запусти бота Перейди в только что созданного бота и нажми Start (или отправь /start). Без этого бот не сможет присылать тебе сообщения.
  3. Узнай свой Chat ID Открой @Getmyid_Work_Bot, нажми Start — он покажет твой числовой chat id. Скопируй его.
  4. Скачай исходники Скачай архив по кнопке Download intelix и распакуй его.
  5. Открой проект в Visual Studio Перенеси папку стилера на рабочий стол, нажми по ней правой кнопкой мыши → «Открыть с помощью» → Visual Studio.
  6. Найди нужный файл В Visual Studio открой Обозреватель решений → CvMega → Plugin → найди строку private static async Task MainAsync(string[] args).
  7. Замени токен и chat id В этом блоке кода замени значения botToken и chatId на свои — токен из @BotFather и chat id из @Getmyid_Work_Bot.

Есть уязвимость через API бота, так как ваш токен находится в коде. Некоторые могут взять ваш билд, достать из него API-токен бота, после чего пересылать все ваши логи себе и забирать их быстрее вас.

Как это контрить:
На каждого человека создавайте отдельного бота. Отправили человеку стилер, он его запустил, забрали лог и сразу удалили этого бота. Тогда, даже если кто-то достанет токен, он уже не сможет получать ваши логи.
